# Contributing to Good First Issues

Thank you for your interest in contributing to Good First Issues!

Good First Issues welcomes contributions from developers of all experience levels, especially first-time open-source contributors.

## Getting Started

1. Fork this repository to your GitHub account.
2. Clone your fork:

   ```bash
   git clone https://github.com/YOUR-USERNAME/goodfirstissues.git
   ```

3. Navigate to the project directory:

   ```bash
   cd goodfirstissues
   ```

4. Create a new branch for your changes:

   ```bash
   git switch -c feature/your-change
   ```

## Making Changes

- Check existing issues before starting a new feature.
- Keep changes focused and easy to review.
- Follow the existing code style and project structure.
- Write clear comments when they help explain your code.
- Never commit passwords, API keys, or other private credentials.

## Before Submitting a Pull Request

- Review your changes carefully.
- Test your changes where applicable.
- Make sure your changes do not introduce unrelated modifications.
- Write a clear commit message describing your work.

Example:

```bash
git add .
git commit -m "docs: improve contribution guidelines"
git push origin feature/your-change
```

## Opening a Pull Request

1. Open your fork on GitHub.
2. Select the branch containing your changes.
3. Click **Compare & pull request**.
4. Provide a descriptive title and explain what you changed.
5. Submit your pull request to the original repository.

## Need Help?

If you are unsure about something, feel free to open an issue or ask questions in an existing discussion.

We appreciate every contribution. Happy contributing!
